Descripción detallada

Gestiona la modificación de los datos de los usuarios.

Permite actualizar los datos principales, la contraseña y los roles asociados a un usuario.

Modifica los datos principales y los roles de un usuario.

Actualiza el nombre, correo y roles del usuario. La contraseña solamente se modifica si se proporciona un nuevo hash.

Parámetros
string$cedulaCédula del usuario que se modificará.
string$nombreNuevo nombre del usuario.
string$correoNuevo correo del usuario.
array$rolesRoles que tendrá el usuario.
string | null$claveHashNuevo hash de contraseña o null para conservar la contraseña actual.
Devuelve
bool true si la modificación se realizó correctamente; false si ocurrió algún error.
