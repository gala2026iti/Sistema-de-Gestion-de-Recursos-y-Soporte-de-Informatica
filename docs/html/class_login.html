Descripción detallada

Gestiona la autenticación de los usuarios.

Utiliza AccesoDatosUsuario para obtener los datos del usuario y verifica que se encuentre activo y que la contraseña ingresada coincida con el hash almacenado en la base de datos.

Login::autenticar ( string $cedula,
string $clave )

Autentica a un usuario mediante su cédula y contraseña.

Primero busca al usuario en la base de datos. Si existe, comprueba que se encuentre activo y posteriormente verifica la contraseña utilizando el hash almacenado.

Parámetros
string$cedulaCédula del usuario.
string$claveContraseña ingresada por el usuario.
Devuelve
Usuario|null Devuelve el objeto Usuario si la autenticación es correcta. Devuelve null si el usuario no existe, está inactivo o la contraseña es incorrecta.
